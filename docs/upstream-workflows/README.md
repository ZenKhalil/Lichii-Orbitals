# Inactive upstream workflow examples

These files preserve inherited build/release/issue automation for reference.
They are outside `.github/workflows`, do not run in this repository, and are
not a supported or validated release process. Do not move them back without
reviewing dependencies, permissions, repository targets and numbering policy.
Numbered Orbitals releases currently use the reviewed build and validation
process described in [ORBITALS_BUILD.md](../ORBITALS_BUILD.md).
